# Sales Insights Dashboard

## Project Overview

This project analyzes sales performance for AtliQ Hardware using Tableau and MySQL.

## Business Problem

The Sales Director lacked real-time visibility into sales performance due to manual Excel reporting.

## Objectives

- Analyze sales performance
- Identify top customers
- Identify profitable markets
- Track revenue trends
- Improve business decision making

## Tools Used

- Tableau Desktop
- MySQL
- SQL

## Features

- Interactive Dashboard
- Revenue KPIs
- Profit Analysis
- Customer Analysis
- Market Analysis
- Dynamic Filters


## Skills Demonstrated

- SQL

- Data Modeling
- Tableau
